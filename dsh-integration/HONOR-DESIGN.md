# MeshMoe 荣誉体系设计（极客社区版）

> 本设计**取代**积分货币制（CREDITS-DESIGN.md 已废弃）。核心转变：贡献者的回报不是"钱"，是**看得见、留得住、晒得出的荣誉**。
> 实证依据：BOINC 峰值约 300 万台设备、Folding@home 约 180 万台设备，零金钱激励，纯靠荣誉点 + 排行榜 + 团队战驱动。这是人类验证过的最大志愿算力网络，我们直接继承其方法论。

## 一、为什么荣誉制优于积分制

| 维度 | 积分制（旧） | 荣誉制（新） |
|---|---|---|
| 激励性质 | 可消费 = 可套利 → 催生薅羊毛、作弊脚本 | 不可消费 = 作弊无利可图 → 防刷成本大降 |
| 用户认同 | "我在打工换token"，贡献者心态变味 | "我是社区共建者"，极客认同 |
| 法律属性 | 接近虚拟货币，灰色地带 | 类似开源贡献者排名，零金融风险 |
| 长期留存 | 消费完就走 | 荣誉只增不减，沉没成本即留存 |
| 极客文化 | 相悖（金钱污染开源精神） | 同源（GitHub star、Linux 贡献者榜同款心理） |

## 二、体系设计

### 1. 贡献值（推荐名：**Joule / 焦耳**，备选：贡献值 / MP）
- 每完成一次网络任务按算力加权计 1-N 焦耳，**只增不减、不可消费、不可转赠**（作弊一经证实清零+公示）
- 永久绑定节点身份，全网可查可验证
- 命名含义：每次推理都是一次能量贡献，极客味 + 中英通用

### 2. 称号等级（开源社区文化词系）
```
L1 Contributor 贡献者   （入网即得）
L2 Maker    建设者      （≥1万焦耳）
L3 Maintainer 维护者    （≥100万焦耳 + 验证通过率≥99%）
L4 Core     核心节点    （≥1亿焦耳 + 服务过塔尖难题）
L5 Legend   传奇        （全网 ≤100 席，社区公示）
```

### 3. 排行榜与战队（BOINC 验证过的留存神器）
- 个人榜 / 城市榜 / **战队榜**（可自建战队：公司、大学、社区、爱好者小组）
- 战队对抗 + 周挑战赛（"本周为社区燃烧最多焦耳的战队"）
- 战队是裂变引擎：拉一个战队 = 拉一批人

### 4. 徽章（可展示、可收藏）
- **创世节点**：前 1000 名入网，永久编号（极客圈的"史前化石"，最稀缺最想晒）
- 里程碑类：首次任务 / 首万次推理 / 连续供网 100 天
- 质量类：验证通过率 99%+ / 零宕机月
- 稀有类：解出过 27B 级难题 / 轨迹被选入下一代训练集（"你的 37 条轨迹参与了 MeshMoe-5 的训练"——署名级荣誉）

### 5. 可分享节点身份卡
自动生成可分享卡片：`节点 #0817 · 等级 Maintainer · 累计帮社区完成 12,480 次推理 · 燃烧 892,301 焦耳 · 折合 41 小时算力`——发朋友圈、放社区签名档、挂 GitHub profile，**每个人的贡献变成社交货币**。

### 6. 用量权益与贡献挂钩（替代"花积分"，但不叫积分）
- **本地推理永远免费无限**（跑在自己电脑上不耗任何资源，这是免注册的根基）
- 只有"调用他人节点"占用**月度社区配额**：配额随贡献等级动态提升（L1 够日常用、L3 可高频调 27B、加急次数更多）
- 配额月底恢复，用完下月再来——**不是余额，不焦虑，不交易**
- 内部仍有一层防滥用的记账逻辑，但对用户只叫"配额"，永不出现"余额/充值/兑换"字样

### 7. 极客透明原则
- 全部开源（节点端、路由算法、荣誉计算公式）
- 公共 dashboard：全网实时任务数、节点分布热力图、总燃烧焦耳数
- 每笔贡献可回溯："你的第 1024 次推理，帮广州一位用户跑了一个爬虫 agent"

## 三、冷启动策略

1. **创世节点计划**：前 1000 名 = 永久编号 + 创世徽章，饥饿营销但真实兑现
2. 创始团队**以身作则**：公开自己的节点编号和贡献值，挂在官网
3. 首批种子战队定向邀请：高校 Linux 社、开源社区、硬件发烧友论坛——这群人本来就是荣誉驱动的
4. 官网一句话定位：**"把你的闲置算力，变成社区的记忆"**

## 四、与现有体系的衔接

- credit 记账层保留为内部防滥用配额的计量单位，不再对外叙事
- 供网分成逻辑保留（70% 归节点），但表现形式从"赚 70 积分"改为"贡献 +70 焦耳"
- 数据回流授权：贡献轨迹 = 荣誉事件（署名进训练集致谢名单），同时仍是防滥用合规的授权凭证
