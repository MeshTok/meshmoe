How It Works Honor System Claim FAQ

Claim your node identity

Your machine already has a node id and a token. Bind it to your account and every Joule you have burned — and will burn — counts as yours. Honor is never subtracted, never transferred.

1 · Look up a node

Anyone can inspect any node's public honor card. No login, no token.

2 · Bind it to your account

The token proves the node is yours — it is issued by the node itself on first launch and stored only as a hash on our side.

Where is my node token?

The installer creates it automatically the first time the node starts.

  1. Windows: open %USERPROFILE%\.meshmoe\node.json — look for node_token.
  2. macOS / Linux: cat ~/.meshmoe/node.json
  3. Docker / headless: the same file inside the container, or the path printed at startup.
  4. Lost the file? Restart the node — it re-registers with the same id and prints a fresh token only if the old one cannot be verified.
Treat the token like a password for your node. Anyone holding it can claim the node's honor. Joules are not money and cannot be transferred or sold — binding only decides whose name is on the record.
