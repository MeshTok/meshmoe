Install MeshMoe

Two ways in. Both give you a free local MeshMoe-4B agent, and both let your machine join the mesh and burn Joules while idle. No account, no API key, no payment.

Option A · for everyone

MeshMoe Node (standalone)

One user-level installer: llama.cpp runtime + MeshMoe-4B (2.7 GB) + edge node. Double-click, then start from the desktop shortcut. No admin rights, no DSH required. Works CPU-only.

Download the latest installer Source & release notes

After install: start-node.cmd → node id prints in the log → check your honor card. Optional run-at-logon: enable-autostart.cmd (one schtasks /delete undoes it).

Option B · if you already use DSH

dsh-plugin-meshmoe

Adds a local meshmoe-local provider to DeepSeek Harness without overwriting your existing configuration, and auto-starts the runtime and mesh node.

Get the plugin 
dsh plugin install dsh-plugin-meshmoe
Requirements
  • Windows 10/11 x64 (other platforms: run node/edge_node.py directly)
  • ~4 GB free RAM for CPU-only; NVIDIA GPU recommended (CUDA runtime bundled)
  • ~3 GB disk for the model

The old Flutter 0.3.x desktop client is deprecated — it only chatted and is no longer developed. 中文说明
