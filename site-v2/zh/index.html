FAQ

真的免费吗？靠什么活？

本地推理永远免费——它跑在你自己的电脑上，我们没有任何成本。社区调用的空闲算力由节点自愿贡献（换焦耳荣誉）。未来收入来自企业 API 和对无卡用户的单向充值，社区用户永远免费。我们不出售数据，不给荣誉明码标价。

焦耳能换成钱吗？

不能，永远不能。焦耳是荣誉，不是货币——不可消费、不可转赠、不可兑换。这正是它干净的原因：没有金融属性，没有套利空间，没有薅羊毛的动机。

会偷我的数据吗？

本地推理的数据 100% 不出门。供网任务的内容只存在于任务通道中。训练数据回流需要你单独勾选授权、默认关闭、随时可撤回，脱敏标准全部公开。

我的电脑很旧，能参与吗？

能。MeshMoe-4B 纯 CPU 4GB 内存即可运行——慢一点，但照样贡献焦耳。有 24GB 显卡？可以装塔尖档 Qwen3.8-27B，处理更难的任务，燃烧更快。

为什么叫 MeshMoe？

Mesh（网格）+ MoE（Mixture of Experts 混合专家）。模型级 MoE 里，路由器把每个词派给最合适的专家子网络；MeshMoe 把这件事放大到网络级——Router 把每个任务派给最合适的那台电脑。百万台电脑，一个专家混合大脑。
